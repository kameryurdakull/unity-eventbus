# Event Bus

Tür güvenli, senkron ve UniTask tabanlı asenkron Unity Event Bus. VContainer kaydı için `builder.RegisterEventBus()` kullanın.

Kurulum adresleri, kullanım örneği ve davranış ayrıntıları için [depo README dosyasına](https://github.com/kameryurdakull/unity-eventbus#readme) bakın. Package Manager > Samples > Basic Usage > Import ile örneği alın.

UniTask 2.5.11 ve VContainer 1.19.0 projeye ayrıca kurulmalıdır.
